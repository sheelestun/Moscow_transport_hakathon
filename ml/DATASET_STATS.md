## Особенности и ловушки

1. **Утечка ответов**: в `train/schedule.csv` и `test/schedule.csv` есть фактическое время прибытия для всех 151
   целевой остановки validate. Это данные из будущего относительно T — **не используем**.
2. **Подсказка `cur_dev_s` частично из будущего**: это (факт − план) на последней остановке с **планом** <= T; у
   **45%** точек этот факт наступает уже после T (в среднем через 129 с, до 10 мин). Для сабмита подсказка разрешена;
   на живом потоке её так не посчитать — для потока обучена отдельная модель на подсказке по GPS (см. `README.md`).
3. **Клоны в тех же моментах T**, что test и validate (96% точек) — модель честно учится на них, поэтому на данных
   хакатона MAE ~40 с, а на новом ТС (LOVO) ~79 с.
4. **Прибытия восстанавливаются из GPS** с медианной ошибкой ~3 с (для остановок без ручной отметки).
